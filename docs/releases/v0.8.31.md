# Honda Box 0.8.31

Adds an experimental Debug switch: **Extend compact climate overlay to system nav area**. Off by default; applies automatically to both the expanded compact bar and its folded handle, including after reopening the overlay. The full climate panel is unchanged.

This changes placement/insets, not the application-overlay layer. Android system bars or a privileged DUDU window can still cover it. Turn the switch off to restore normal positioning if the compact panel disappears. Android 7–10 use legacy layout flags; device/firmware behavior needs checking.

## Русский

В Debug добавлен экспериментальный переключатель «Расширять компактный климат в область системной навигации». По умолчанию выключен, применяется автоматически к строке и свёрнутой полоске. Большая панель не меняется. Если строка окажется под навигацией и пропадёт, отключите настройку для возврата к обычному положению.

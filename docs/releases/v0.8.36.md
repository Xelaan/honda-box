# Honda Box 0.8.36

## Русский

- **Трек Android в оверлеях**: отдельная настройка в разделе «Плееры». На AUX или при неизвестном штатном источнике показывает название/исполнителя в громкости и уведомлении нового трека. Нажатие открывает Android-плеер. Нужен системный доступ к уведомлениям для MediaSession; тексты уведомлений не читаются. Настройка независима от автопаузы AUX.
- **Климат Civic 2006–2011 LZ(HZ)**: отдельный декодер LOW15729093/HIGH15794629, корректный масштаб температур, AUTO/OFF и компактная панель. При одной доступной температуре обе стороны синхронны, DUAL скрыт; без направления в компактной строке показан AUTO. LOW проверен по реальному логу; HIGH пока только по общему обработчику и синтетическим тестам.
- **Car Info Civic**: поле98 отображается как расстояние в км и больше не рассматривается как источник аудио. Значение подтверждено кодом FYT; общий это пробег или поездка, и реальная передача на машине ещё требуют проверки. Экран сам не открывается.
- **Debug**: последние экспериментальные данные часов TYPE0A с сырыми байтами и неизвестными форматами. Не меняет часы автомобиля.
- Обновлены README, инструкции RU/EN и таблицы автомобилей/CAN-box: отдельно проверенная, частичная и предполагаемая совместимость. XBS/Acura не заявлены полностью поддержанными.

**Установка:** основной `Honda-Box-0.8.36.apk` поверх текущего `com.crewbeat.hondabox` сохраняет настройки. Ярлыки не изменились. Для первой установки скачайте Setup Pack: основной APK, четыре ярлыка, инструкции, таблицы совместимости, проверки SHA-256 и опциональный официальный Shizuku. Для Android-треков откройте Настройки → Плееры и выдайте доступ к уведомлениям соответствующей кнопкой.

## English

- Independent **Android track in overlays** setting: reads MediaSession title/artist on AUX or an unknown OEM source, updates volume/track cards, and opens the Android player on tap. Requires notification access; notification text is not read. AUX pause/resume remains separate.
- Dedicated **Civic 2006–2011 LZ(HZ)** climate route: LOW15729093 validated against a real capture; HIGH15794629 shares the handler and has synthetic coverage only. Correct temperature scaling, AUTO/OFF behavior, mirrored single-zone setpoint, hidden DUAL and compact AUTO fallback.
- Civic **Car Info Distance** reads FYT98 as kilometres, never as an audio source. Distance meaning (trip/odometer) and actual vehicle transmission remain unverified. No automatic Car Info launch.
- Experimental **TYPE0A clock** candidates retained in Debug with raw bytes; unfamiliar formats remain unknown. No clock writes.
- Updated bilingual setup and compatibility documentation, distinguishing supported, partial and unverified configurations.

Install the main APK over the existing installation to retain preferences; launchers are unchanged. The Setup Pack contains five Honda APKs, optional official Shizuku, instructions and checksums. Enable notification access from Settings → Players for Android metadata. Emulator/log validation does not establish every vehicle/adapter or outgoing audio-command combination.

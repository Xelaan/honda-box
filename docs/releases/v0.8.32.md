# Honda Box 0.8.32

Players fit the available window without vertical scrolling. Below 900 dp wide, the illustration card is hidden. Track titles use the remaining height with an ellipsis while keeping timer, playback context, discs/stations and transport controls visible. The illustration returns when the window becomes wider.

In short CD windows, all six discs appear in one row with disc glyphs and numbers. Taller windows use two rows. Selected disc state survives resizing.

Install the main APK over the existing `com.crewbeat.hondabox` app. Launcher APKs are unchanged and do not need reinstalling. Includes the experimental Debug navigation-area setting introduced in 0.8.31.

## Русский

Плееры размещаются без вертикальной прокрутки. В окне уже 900 dp иллюстрация скрывается, а информация занимает доступную ширину. Длинные названия сокращаются с многоточием, сохраняя место для таймера, статуса, дисков/станций и кнопок.

В невысоком окне CD все шесть дисков отображаются одним рядом со значками и номерами. На высоком окне возвращаются два ряда. Выбранный диск сохраняется при изменении размеров.

Установите основной APK поверх текущего приложения `com.crewbeat.hondabox`. Ярлыки не изменились и не требуют переустановки. Экспериментальная настройка области навигации из 0.8.31 включена.

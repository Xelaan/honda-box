# Honda Box 0.8.33

The visible next-track announcement now follows incoming TITLE updates, including a late title replacing the track-number fallback. It refreshes the existing card without restarting its animation or four-second hide timer.

Player Previous/Next buttons are slightly wider and account for localized label width, keeping Russian text on one line in narrow windows.

Background operation adds bounded recovery, FYT ACC wake/sleep handling and a periodic fallback while the device is awake. Manual Stop remains respected. Settings include offline FYT/DUDU setup and troubleshooting guides in English and Russian. Vendor autostart/keep-alive configuration is still required where the firmware restricts background apps; see [background operation](https://github.com/Xelaan/honda-box/blob/v0.8.33/docs/background-operation.md).

Explicit OEM menu-close packets dismiss the shared menu for CD, USB and iPod; verified with actual emulator overlay windows. No guessed close event from TITLE changes was added.

Install the main APK over the existing `com.crewbeat.hondabox` app. Launcher APKs are unchanged and do not need reinstalling. Includes the responsive players and optional navigation-area setting from 0.8.31/0.8.32.

## Русский

Видимое уведомление нового трека обновляется при получении TITLE, включая название, пришедшее после номера трека. Обновление сохраняет текущее окно, анимацию и исходный таймер скрытия.

Кнопки «Предыдущий»/«Следующий» немного шире и учитывают длину перевода, чтобы текст помещался в одну строку и в узком окне.

Добавлены восстановление фоновой службы, обработка FYT ACC и периодическая проверка при бодрствующем устройстве. Ручная остановка службы учитывается. В настройках доступны инструкции для FYT/DUDU и помощь на русском и английском. Настройки автозапуска и сохранения приложений в памяти на самой магнитоле по-прежнему важны.

Явный штатный сигнал закрытия меню проверен для CD, USB и iPod. Изменение текста TITLE само по себе не считается закрытием меню.

Установите основной APK поверх текущего `com.crewbeat.hondabox`. Ярлыки переустанавливать не нужно.

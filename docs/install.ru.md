# Honda Box 0.8.33 — установка на FYT / DUDU

Поддерживаемая конфигурация: Honda Accord VIII / Spirior 2009–2013, FYT CAN-профиль **6291908**, BSJ V704. Требуется **Android 7.0 / API 24 или новее**. Приложение использует штатные аудио- и климатические данные Honda; это не обновление прошивки магнитолы или CAN-адаптера.

## Содержимое комплекта

| Файл | Назначение |
| --- | --- |
| `Honda-Box-0.8.33.apk` | Honda Box Service: служба, интерфейс и оверлеи |
| `Honda-Box-Launcher-1.3.apk` | Ярлык Honda Box, открывающий главный экран |
| `Honda-Radio-Launcher-1.5.apk` | Ярлык Radio |
| `Honda-CD-Launcher-1.5.apk` | Ярлык CD |
| `Honda-USB-Launcher-1.6.apk` | Ярлык Honda USB: один экран для USB и iPod |
| `shizuku-v13.6.0.r1086.2650830c-release.apk` | Необязательный официальный Shizuku для скрытия штатных окон |
| `INSTALL-ADB.py` | Необязательная установка пяти Honda APK с компьютера через ADB |
| `stock_overlay_adb.py` | Необязательная настройка штатных оверлеев через ADB, с сохранением и восстановлением исходного режима |
| `SHA256SUMS.txt`, `BUILD-VERIFICATION.json` | Контрольные суммы, идентификаторы, версии, сертификаты и результаты проверки файлов |

В комплекте также есть английская инструкция, описание релиза и лицензии. Отдельный iPod APK не нужен. Тестовые приложения, прошивка, личные логи и ключи подписи не включены.

## Переход со старых локальных сборок

Новые идентификаторы начинаются с **`com.crewbeat.hondabox`**. Старое приложение `dev.alex.fyt.probe` и старые ярлыки **не заменяются автоматически**. Настройки, разрешения и доступ Shizuku нужно задать заново.

1. Если старый Honda Box скрывал штатные окна CANBUS, сначала в нём восстановите исходное разрешение. Не удаляйте старую службу и не очищайте её данные до восстановления: сохранённый режим находится в её настройках.
2. Остановите старую службу и выключите её автостарт в приложении и DUDU, чтобы две службы не показывали одинаковые оверлеи.
3. Установите новый комплект и настройте его по шагам ниже. После проверки старые Honda Box/Radio/CD/USB-ярлыки и старую службу можно удалить через настройки Android. Это удалит их старые данные.

Если уже установлена версия с тем же `com.crewbeat.hondabox` и нашим релизным сертификатом, установка поверх неё сохраняет настройки. Dev-сборка из самостоятельного checkout подписывается другим ключом и не сможет обновиться поверх этого релиза. При конфликте подписи сохраните нужные настройки, удалите только конфликтующее Honda-приложение и установите релиз заново; данные этого приложения будут удалены. Не удаляйте системные `com.syu.ms` / `com.syu.canbus`.

## Установка на магнитоле

1. Распакуйте Setup Pack ZIP на компьютере. Скопируйте APK на флешку, откройте её в файловом менеджере Android. Не помещайте файлы в режим обновления прошивки.
2. Установите **Honda-Box-0.8.33.apk** первым. При необходимости разрешите файловому менеджеру установку из этого источника.
3. Установите **Honda-Box-Launcher-1.3.apk** и нужные ярлыки Radio, CD, Honda USB. Их можно установить все; для USB/iPod используется один ярлык.
4. Откройте ярлык **Honda Box**. **Honda Box Service** запускает службу без окна — для интерфейса нужен отдельный ярлык Honda Box. Соединение с FYT начинается автоматически. Убедитесь, что магнитола уже настроена на профиль 6291908; приложение не меняет профиль самостоятельно.
5. Откройте Settings → **Allow display over other apps** и разрешите показ поверх других приложений. На Android 13+ также разрешите уведомления, если Android запросит их.
6. Разрешите фоновую работу/исключение из оптимизации батареи в настройках. В DUDU добавьте **Honda Box Service** в автостарт и список сохранения при сне/Keep alive. При необходимости обновите список приложений или перезапустите лаунчер, чтобы новые ярлыки появились.
7. Выберите язык, тему и акцент. Большая климатическая панель и компактная строка включаются **независимо**; пояснения и кнопки примеров находятся в разделе климата. Для автоматической темы по восходу/закату задайте место; разрешение геолокации нужно только для получения текущего места.
8. Проверьте в машине переключение FM/CD/USB/iPod кнопкой MODE, громкость и климат. Если команды выбора/Previous/Next не поддержаны конкретной прошивкой, используйте штатные кнопки автомобиля. Логи по умолчанию выключены; включить, сбросить и экспортировать запись можно в Debug.

Штатный iPod определяется по наблюдаемым признакам этого адаптера; после подключения возможна небольшая задержка. Непереданные название трека, таймер, RDS-текст или состояния климата приложение не восстанавливает из воздуха. У новой сборки проведены проверки в эмуляторе; работа конкретной прошивки и поведение сна DUDU проверяются на магнитоле.

## Автозапуск и глубокий сон

Откройте **Honda Box → Настройки → Фоновая работа**: там доступны инструкции **«Настройка FYT»**, **«Настройка DUDU»** и **«Проверка и помощь»** без интернета. В штатной FYT добавьте **Honda Box Service** в **Settings → User → Application Settings** для загрузки и пробуждения. В DUDU OS используйте доступные списки автозапуска и Keep alive при сне; DUDU Launcher поверх штатной FYT может требовать настройки через FYT. Названия пунктов зависят от прошивки.

Запуск после загрузки/зажигания и восстановление службы включены по умолчанию. Периодическая проверка при бодрствующем устройстве дополняет штатный автозапуск, но не гарантирует обход принудительной остановки прошивкой. **Stop** блокирует автоматические перезапуски; для возобновления откройте интерфейс **Honda Box**. Отдельно проверьте перезагрузку Android и цикл ACC OFF/глубокий сон/ACC ON. Подробнее — в приложенном [руководстве по фоновой работе](background-operation.md#русский).

## Необязательно: скрытие штатных окон через Shizuku

Для обычного чтения FYT и оверлеев Honda Box **Shizuku не нужен**. Он нужен только для управления разрешением штатного `com.syu.canbus`.

1. Установите включённый официальный Shizuku. Если у вас уже есть совместимый Shizuku, переустанавливать или понижать его версию не нужно.
2. Откройте Shizuku → запуск через компьютер → показать команду. Подключите магнитолу по ADB и выполните **команду, показанную вашей установленной версией Shizuku**. При наличии Wireless debugging можно использовать предлагаемый Shizuku способ запуска. [Официальная инструкция](https://shizuku.rikka.app/guide/setup/).
3. Honda Box → Settings → Stock CANBUS windows → Connect / refresh Shizuku; разрешите Honda Box доступ.
4. Включите Hide stock CANBUS popups. Honda Box сохраняет исходный AppOps-режим и проверяет применение. Выключение переключателя восстанавливает сохранённый режим.
5. Перед удалением Honda Box/очисткой данных верните исходное разрешение. После перезагрузки для изменения режима может понадобиться снова запустить Shizuku.

Настройка касается **всех** оверлеев `com.syu.canbus`, а не отдельного окна: меню, Car Vol, климат и другие окна. Отдельная системная панель громкости `com.syu.ms` ею не управляется. Приложение не отключает системную службу FYT или CANBUS. Если прошивка использует иной тип окна, настройка может не скрыть его.

Альтернатива с компьютера: `python3 stock_overlay_adb.py status --serial SERIAL`; для `hide` и `restore` укажите `--state original-canbus-overlay.json`. Сохраните этот файл для отката и используйте тот же SERIAL. Скрипт не нужен при использовании настройки Shizuku.

## Необязательно: установка через ADB

Нужны Python 3 и современные [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools). Разрешите ADB на магнитоле, выполните `adb devices -l` и подтвердите разрешение компьютера.

Из распакованного комплекта:

```sh
python3 INSTALL-ADB.py --serial SERIAL
```

Подставьте серийный номер или IP:port из `adb devices -l`. Скрипт сверяет SHA-256 и устанавливает пять Honda APK без incremental install; не устанавливает Shizuku автоматически, не удаляет приложения и не меняет прошивку или профиль CAN. После установки вручную выполните шаги разрешений/автостарта выше. Для нестандартного пути добавьте `--adb /path/to/adb`.

## Проверка скачанных файлов

После распаковки: `sha256sum -c SHA256SUMS.txt` (Linux) или `shasum -a 256 -c SHA256SUMS.txt` (macOS). В Windows: `Get-FileHash .\Honda-Box-0.8.33.apk -Algorithm SHA256` и сравните значение с SHA256SUMS.txt. Отдельный `.zip.sha256` в релизе содержит контрольную сумму архива.

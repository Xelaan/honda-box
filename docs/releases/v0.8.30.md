# Honda Box 0.8.30

First public installable release of the source published at Xelaan/honda-box. Requires Android 7/API 24+, FYT profile 6291908 and BSJ V704.

- New `com.crewbeat.hondabox` package family; signed main app plus Honda Box / Radio / CD / USB launchers. One USB launcher handles USB and iPod.
- Current source-selector/player design, adapted light/dark illustrations, accent-tinted cards, source highlighting and player/TITLE help.
- Updated full climate settings icon, player control layout and single-line translucent track/station announcements.
- Independent large/compact climate settings, persistent folded handle and optional side controls; source/volume/menu overlays, headless start, theme/language/accent settings and opt-in diagnostics are included.
- Russian/English installation guides, optional official Shizuku, ADB helpers, licenses and checksums in one Setup Pack ZIP.

**Migration:** installs separately from the older `dev.alex.*` packages. Stop their service/autostart; restore any stock-overlay permission they saved before uninstalling them. Set the new app's preferences/permissions again. Future updates with the same new package and release certificate preserve preferences.

**Validation:** builds/signatures/package IDs/checksums are verified; emulator installation and synthetic UI checks are performed for this release. No new physical-head-unit validation is claimed. Outgoing audio commands depend on firmware; unsupported data is not invented.

## Русский

Первый публичный установочный релиз. В одном ZIP — Honda Box Service 0.8.30, ярлык Honda Box 1.3, Radio/CD 1.5, общий USB/iPod-ярлык 1.6, инструкции на двух языках, необязательный официальный Shizuku, ADB-помощники, лицензии и контрольные суммы.

Содержит текущий дизайн главного экрана/плееров, светлые и тёмные иконки, климатические панели, уведомления, штатное меню и диагностику. Пакеты переименованы в `com.crewbeat.hondabox.*`: старые локальные сборки не заменяются автоматически; настройки и разрешения нужно задать заново. Проверки выполняются в эмуляторе; конкретная магнитола и её прошивка требуют проверки в машине.

# Honda Box 0.8.35

Powered AUTO climate with valid set temperatures now keeps the compact climate panel visible when the adapter reports fan0. It displays AUTO without inventing a fan speed. The original stuck-power OFF workaround remains in place.

Player volume and the volume overlay now prefer validated BSJ volume when FYT field132 stops updating. The source label accepts raw radio band data, and TYPE06 fills the six changer-state fields using the stock decoder mapping. Existing USB/iPod inference and AUX guards are preserved.

Debug includes connection-level packet receipt counters, last lengths/ages and source/volume transport. This bounded diagnostic works with recording off, survives log reset, and resets on reconnect/profile change. Missing packets are not evidence that a feature is unsupported. TYPE0A/0B/7B remain unassigned; their possible clock/display correlations are diagnostic hypotheses only.

Install the main APK over the existing com.crewbeat.hondabox installation to retain settings. Launcher APKs are unchanged. Emulator regression and private raw-stream replay passed; second-car CD/USB/iPod and radio hardware behavior still needs a recording exercising those sources. AUTO airflow remains the existing windshield fallback when direction bits are absent; it is not a measured automatic direction.

## Русский

Компактная панель климата больше не исчезает в AUTO, если адаптер сообщает fan0 при включённом климате и заданной температуре. Вместо нулевой скорости отображается AUTO. Обход застывшего бита питания на первом автомобиле сохранён.

Плееры и оверлей громкости используют валидированное значение BSJ, если поле132 FYT застывает. Название источника учитывает диапазон радио из сырых пакетов. TYPE06 расшифровывает состояния шести дисков по штатной схеме. Прежнее определение USB/iPod и защита AUX сохранены.

В Debug добавлена сводка реально полученных пакетов: счётчики, последние длины и давность, а также путь получения источника/громкости. Она работает без записи лога, сохраняется при его сбросе и очищается при переподключении/смене профиля. Отсутствие пакетов не доказывает отсутствие функции. TYPE0A/0B/7B остаются неопознанными; возможная связь с часами/штатным дисплеем пока только гипотеза.

Основной APK устанавливается поверх текущего com.crewbeat.hondabox с сохранением настроек. Ярлыки не изменились. Регрессионные тесты и повторное воспроизведение лога прошли; CD/USB/iPod и радио второго автомобиля требуют отдельной проверки. В AUTO при отсутствии битов направления остаётся прежняя подстановка иконки стекла; реальное автоматическое направление неизвестно.

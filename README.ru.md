# Honda Box

Приложение для отображения штатных аудио- и климатических данных Honda на Android-магнитолах FYT с адаптером BSJ. [English README](README.md).

Проверенная конфигурация: Accord VIII / Spirior 2009–2013, профиль FYT **6291908**, BSJ V704. Требуется Android 7 / API 24+. Основной пакет — `com.crewbeat.hondabox`.

В самом низу настроек переключатель **«Обрабатывать как Honda Accord»** позволяет применять обработку и обходные решения профиля 6291908 к любому выбранному CAN-профилю. По умолчанию выключен; для самого 6291908 обработка действует всегда. Он включает определение питания климата по вентилятору и DUAL по температурам, декодирование BSJ, определение USB/iPod, кэши меню/станций и команды плееров. Профиль магнитолы не меняется, кэши разделены по реальному профилю. При изменении настройки приложение переподключается к службе FYT; совместимость с другим адаптером нужно проверить в автомобиле.

### Источник и состояние питания аудио

Оверлей источника появляется при смене режима и запуске/пробуждении службы. Проверенное состояние питания штатного аудио отображается отдельным чипом OFF на главном экране; оверлей можно оставлять видимым, пока аудио выключено. AUX можно переименовать в настройках, например в Android.

В настройках плееров можно управлять музыкой Android при смене AUX. Пауза при уходе с AUX включена по умолчанию. Для возвращения доступны «Всегда воспроизводить», «Возобновлять после автопаузы» (по умолчанию) и «Ничего не делать». Используются [медиакнопки Android](https://developer.android.com/reference/android/media/AudioManager#dispatchMediaKeyEvent(android.view.KeyEvent)); плеер должен их поддерживать. Уже приостановленная музыка по умолчанию не запускается.

### Диагностика

Debug разделяет колбэки FYT и расшифрованные поля BSJ, сохраняет последние значения и явно отмечает неподтверждённые каналы. Запись включается по запросу; доступны сброс, экспорт и анализ пакетов. Экспериментальные команды отправляются вручную — скриншоты не подтверждают их работу на автомобиле.

**Колбэки радио / диагностика BSJ**

| Светлая тема | Тёмная тема |
| --- | --- |
| ![Колбэки радио / диагностика BSJ — светлая](docs/images/features/debug-radio-day.png) | ![Колбэки радио / диагностика BSJ — тёмная](docs/images/features/debug-radio-night.png) |

Это интерфейс к данным FYT и пакетам адаптера BSJ, а не подтверждённый поток исходных Honda CAN-ID/DLC. Распознавание iPod использует наблюдаемые признаки конкретного профиля. Команды аудио зависят от прошивки; климат отображается без отправки команд. Car Info экспериментальный: неподтверждённые trip-показатели не выдаются за расшифрованные. Передача RDS station name/RadioText не подтверждена.

## Установка

Скачайте **Setup Pack ZIP** из [GitHub Releases](https://github.com/Xelaan/honda-box/releases/latest): в нём основной APK, четыре ярлыка, инструкции на русском и английском, контрольные суммы и необязательный Shizuku. [Подробная инструкция](docs/install.ru.md).

Установите основной APK и нужные ярлыки Honda Box, Radio, CD, USB. Отдельный iPod-ярлык не нужен. Значок службы запускает чтение в фоне; ярлык Honda Box открывает главный экран.

Для автозапуска после загрузки и глубокого сна добавьте **Honda Box Service** в FYT **Settings → User → Application Settings**. Обработка ACC и периодическая проверка дополняют восстановление. [Фоновая работа и ограничения](docs/background-operation.md#русский).

Разрешите отображение поверх других приложений и фоновую работу. Настройки большой и компактной климатических панелей независимы. При необходимости включите Keep alive в DUDU. Для управления штатным оверлеем отдельно установите и запустите Shizuku через ADB. Логи по умолчанию выключены; запись и сброс находятся в Debug. Приложение не может гарантировать обход ограничений фоновых процессов производителя.

## Идентификаторы

- Служба: `com.crewbeat.hondabox`.
- Главный экран: `com.crewbeat.hondabox.launcher`.
- Ярлыки: `com.crewbeat.hondabox.radio`, `com.crewbeat.hondabox.cd`, `com.crewbeat.hondabox.usb`.

Это новые Android-пакеты. Они устанавливаются отдельно от прежнего `dev.alex.fyt.probe`; настройки и разрешения старого приложения автоматически не переносятся. Для USB и iPod используется один ярлык.

## Сборка

Нужны Python 3.9+, JDK 17+ и Android SDK с platform android-33 / Build Tools 36.0.0. Сборка без Gradle и сетевой загрузки библиотек:

```sh
export ANDROID_SDK_ROOT="$HOME/Library/Android/sdk"
export JAVA_HOME="/путь/к/jdk"
python3 build.py
python3 build_launchers.py
```

На этом Mac JDK Android Studio определяется автоматически. Результаты записываются в `dist/`, промежуточные файлы — в `build/`. Версии берутся из AndroidManifest.xml. Переменные для других окружений перечислены в [основном README](README.md#build).

Для обновлений в пределах нового пакета нужен прежний ключ подписи. Он сохранён локально и исключён из Git. В чистой копии создаётся новый dev-ключ; для совместимого релиза задайте `HONDA_KEYSTORE` и `HONDA_KEYSTORE_PASSWORD`.

python3 -m unittest discover -s tools -p 'test_*.py'

# Honda Box 0.8.34

Android playback can now pause automatically when leaving AUX. On return to AUX, choose **Always play**, **Resume if auto-paused** (default), or **Do nothing**. With the default, music that was already paused stays paused. These options are in **Settings → Audio · player screens → AUX / Android playback**. The Android player must accept media-button commands; firmware/player behavior still needs checking on the head unit.

The optional **Process as Honda Accord** checkbox applies Accord 6291908 processing and workarounds to any selected CAN profile: fan-based climate power, inferred DUAL, raw BSJ source/media interpretation, USB/iPod detection, menu/preset caches and player controls. It defaults to off; native 6291908 processing is always active. The head unit's actual CAN profile stays unchanged and caches remain isolated by that real profile. Changing the checkbox reconnects read-only FYT subscriptions. Find it near the bottom of Settings, above the final **Debug** button. Compatibility with another protocol is not guaranteed.

Next-track announcements stay visible for **five seconds** (one second longer). iPod is labeled simply **iPod**, without the menu-detection suffix in the volume overlay or player illustration panel; diagnostic evidence remains available in Debug.

Install the main APK over your existing `com.crewbeat.hondabox` installation to retain settings. Launcher APKs are unchanged. If the legacy `dev.alex.fyt.probe` app is still installed, save any needed logs, restore any stock-overlay permission it changed, then stop it and remove it to prevent two services/duplicate overlays. USB and iPod continue to share one launcher.

## Русский

Добавлено управление музыкой Android при смене AUX: пауза при уходе включена по умолчанию. При возвращении доступны **«Всегда воспроизводить»**, **«Возобновлять после автопаузы»** (по умолчанию) и **«Ничего не делать»**. Уже приостановленная музыка по умолчанию не запускается. Настройки находятся в **«Аудио · экраны плееров» → «AUX / воспроизведение Android»**. Плеер Android должен поддерживать медиакнопки; работу с конкретным плеером на магнитоле нужно проверить.

Переключатель **«Обрабатывать как Honda Accord»** позволяет применять обработку профиля 6291908 к любому выбранному CAN-профилю: определение питания климата по вентилятору, DUAL по температурам, декодирование BSJ, распознавание источника и USB/iPod, кэши меню/станций и команды плееров. По умолчанию выключен; для самого 6291908 обработка действует всегда. Реальный профиль магнитолы не меняется, кэши разделены по нему. При изменении настройки приложение переподключается к службе FYT без команд смены профиля. Переключатель находится внизу настроек, перед последней кнопкой **Debug**. Совместимость с другим протоколом требует проверки.

Уведомление нового трека теперь показывается **пять секунд**. В оверлее громкости и боковой панели плеера отображается просто **iPod**, без приписки об определении через меню. Диагностическая информация сохранена.

Основной APK устанавливается поверх текущей `com.crewbeat.hondabox` с сохранением настроек. Ярлыки не изменились. Если осталась старая `dev.alex.fyt.probe`, сохраните нужные логи, верните изменённое ею разрешение штатного оверлея, затем остановите её и удалите, чтобы не работали две службы. Для USB/iPod достаточно одного общего ярлыка.
